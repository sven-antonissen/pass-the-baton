# 宣言:Pass the Baton(传递接力棒)

## 核心主张

**适用于民众的规则,也应适用于领导他们的人。**

世界各地的人,到了一定年龄,都会把工作交给下一代。我们请求领导人也这样做。这不是不信任老年人,而是尊重新老更替。

## 为什么:问题所在

在世界各地,许多领导人的年龄早已远超本国公民退休的年龄。无论民主国家还是威权政体,都是如此。

- **双重标准。** 护士、建筑工人、教师,到了年纪都要交班。可决定千百万人命运的人,往往干到生命的最后一刻。
- **目光短浅。** 气候、债务和养老金方面的决定,影响最大的是那些将亲身承担后果的几代人。
- **更新受阻。** 一直不肯离开的人,没有给新想法、新面孔和新活力留出位置。
- **对职责的投入不足。** 领导一个国家,需要每天全身心投入。这在任何年龄都是沉重的任务,年事已高时更是如此。

## 我们的诉求

**凡已达到本国法定退休年龄(最迟为67岁)的人,不再开始最高职务的新一届任期。**

- 适用于全世界,适用于每一个国家、每一种政体,先从最高职务做起:国家元首、政府首脑和部长。第二阶段,我们将把这一诉求扩展到其他政治职务。
- 把年龄上限与民众早已接受的标准挂钩:退休年龄,并设定全球上限为67岁。
- 已经开始的任期可以任满。但不再开始新的任期。
- 普通公民仍可自由地继续工作。领导一个国家的人肩负更重的责任,适用更严格的标准,就像飞行员和法官一样。

## 我们的原则

1. **平等。** 领导人与他们所服务的公民,适用同样的年龄规范。
2. **尊重。** 我们并不反对老年人。经验依然宝贵,可以作为顾问、导师或大使继续发挥作用。
3. **更新。** 传递接力棒是领导力的体现,而不是失败。
4. **非暴力。** 我们靠说服,绝不使用武力。
5. **独立。** 我们不站队,不分左右。这一规范适用于所有人。

## 回应质疑

| 质疑 | 我们的回答 |
| --- | --- |
| 年龄不能说明个人的情况。 | 没错,但我们早已接受法官和飞行员有固定的年龄限制。一条清晰的规则,比每次都争论谁“还够格”更公平。 |
| 这是年龄歧视。 | 每个人都保有继续工作的权利。只有最高职务适用更严格的标准,因为它关系到千百万人的生活。 |
| 选民必须有自由选择的权利。 | 选民早已接受各种限制,比如任期限制和最低年龄要求。最高年龄限制正是与之对应的另一面。 |
| 危机时刻,经验最重要。 | 这些经验不会消失。卸任的领导人可以提供建议、居中斡旋、鼓舞人心,而不必掌握权力。 |
| 在独裁国家,人民没有发言权。 | 正因如此,这必须成为全世界的共同规范。别处越是理所当然,对回避这一规范的人施加的压力就越大。 |

## 我们怎么做:象征、时刻、行动

- **象征:接力棒。** 一根接力棒,可以是图像、手势,也可以是实物。人们在网上和街头互相传递。在每一种语言和文化中都一眼可识。
- **话题标签:** #PassTheBaton,以及各地的本地版本,例如 #传递接力棒。
- **时刻:每年一个全球行动日。** 在同一天,各地的人们在广场、工作场所和网络上,象征性地传递接力棒。
- **面孔。** 既有年轻人,也有已经交棒的退休者。这表明,这不是年轻人对老年人。
- **本地化。** 每个国家把诉求与本国的退休年龄和本国的领导人联系起来。
- **第一步。** 尽快开始,分两个阶段:先在线上(宣言、可供报名的网站、话题标签),等到若干国家都有了支持者,再举办第一个线下行动日。

## 可能的代言人

有力的代言人本身就是这一理念的化身。可以接触的人选类型:

| 类型 | 为什么有效 |
| --- | --- |
| 主动提前卸任的前领导人 | 活生生的证明:卸任本身就是一种领导力。可信度最高。 |
| 亲自交过棒的退休者 | 证明这不是“年轻人对老年人”。能打动年长的选民。 |
| 接力项目运动员 | 接力棒就是他们的本行。知名度高、讨人喜欢,政治上中立。 |
| 年轻的活动人士或学生 | 在年轻人和社交媒体上带来活力和影响力。 |
| 一老一少的搭档 | 本身就是“传递”的画面。可能是最有力的选择。 |
