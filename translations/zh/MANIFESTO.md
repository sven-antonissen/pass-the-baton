# 宣言：Pass the Baton

## 核心主张

**适用于人民的规则，也应适用于领导他们的人。**

在世界各地，人们到了一定年龄就会把工作交给下一代。我们请求领导人也这样做。这不是出于对老年人的不信任，而是出于对更新的尊重。

## 为什么：问题所在

在世界各地，许多领导人的年龄远远超过了本国公民退休的年龄。无论民主国家还是威权政体，都是如此。

- **双重标准。** 护士、建筑工人、教师都会交出自己的工作。而决定数百万人命运的人，往往一直干到最后。
- **短视。** 有关气候、债务和养老金的决策，影响最大的是将亲自承担后果的几代人。
- **更新受阻。** 永不离开的人，不给新思想、新面孔和新活力留出空间。
- **对职责的投入不足。** 领导一个国家需要每天全身心投入。这在任何年龄都是一项繁重的任务，在高龄时更是如此。

## 我们的诉求

**凡已达到本国法定退休年龄的人，最迟到67岁，不再开始最高职位上的新任期。**

- 适用于全世界，每个国家、每种政体，首先从最高职位开始：国家元首、政府首脑和部长。第二阶段，我们将其扩展到其他政治职位。
- 把年龄限制与人们已经接受的标准挂钩：退休年龄，并设定全球统一的上限67岁。
- 已经开始的任期可以完成，但不再开始新的任期。
- 普通公民仍可自由地继续工作。领导一个国家的人肩负更重的责任，适用更严格的标准，就像飞行员和法官一样。

## 我们的原则

1. **平等。** 领导人与他们所服务的公民适用同样的年龄标准。
2. **尊重。** 我们并不反对老年人。经验依然宝贵，可以以顾问、导师或大使的身份发挥作用。
3. **更新。** 交接接力棒是一种领导行为，而不是失败。
4. **非暴力。** 我们以说服的方式行动，绝不使用武力。
5. **独立。** 我们不站在任何一方，不分左右。这一标准适用于所有人。

## 对反对意见的回应

| 反对意见 | 我们的回应 |
| --- | --- |
| 年龄说明不了个人的情况。 | 的确如此，但我们已经接受对法官和飞行员设定固定的年龄限制。明确的规则，比每次争论谁“还够格”要公平。 |
| 这是年龄歧视。 | 每个人都保有继续工作的权利。只有最高职位适用更严格的标准，因为它影响数百万人的生活。 |
| 选民必须有自由选择的权利。 | 选民已经接受了各种限制，例如任期限制和最低年龄。最高年龄是它们合乎逻辑的对应。 |
| 危机时刻，经验最重要。 | 这些经验不会消失。卸任的领导人可以不掌权而提供建议、斡旋和激励。 |
| 在独裁国家，人民没有发言权。 | 正因如此，这必须成为全球性的准则。它在别处越是理所当然，对逃避它的人的压力就越大。 |

## 我们怎么做：象征、时刻、行动

- **象征：接力棒。** 一根接力棒，可以是图像、手势或实物。人们在网上和街头把它传给彼此。在每一种语言和文化中都能被认出。
- **话题标签：** #PassTheBaton，以及本地版本，例如 #传递接力棒。
- **时刻：每年一个全球行动日。** 在同一天，世界各地的人们在广场、工作场所和网上象征性地传递接力棒。
- **面孔。** 既有年轻人，也有已经交棒的退休者。这表明这不是年轻人对抗老年人。
- **本地化。** 每个国家把诉求与本国的退休年龄和本国的领导人联系起来。
- **第一步。** 尽快开始，分两个阶段：先在线上（宣言、可报名的网站、话题标签），待多个国家出现支持者后，再举办第一个线下行动日。

## 可能的代言人

有力的代言人能体现这一主张。可以接触的人物类型：

| 人物类型 | 为什么有效 |
| --- | --- |
| 自愿并提早卸任的前领导人 | 活生生的证明：交棒是一种领导行为。可信度最强。 |
| 亲自交过棒的退休者 | 证明这不是“年轻人对抗老年人”。能打动年长的选民。 |
| 接力运动员 | 接力棒就是他们的本行。知名、讨人喜欢，政治上中立。 |
| 年轻的活动人士或学生 | 在年轻人和社交媒体上带来活力和影响力。 |
| 一对搭档：一位年长，一位年轻 | 本身就是传递接力棒的画面。可能是最有力的选择。 |
