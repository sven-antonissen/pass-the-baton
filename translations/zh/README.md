# Pass the Baton(传递接力棒)

**适用于民众的规则,也应适用于领导他们的人。**

世界各地的人,到了一定年龄,都会把工作交给下一代。这场运动请求领导人也这样做。

## 我们的诉求

**凡已达到本国法定退休年龄(最迟为67岁)的人,不再开始最高职务的新一届任期。**

这不是不信任老年人,而是尊重新老更替。

我们坚持非暴力、不分党派。欢迎使用话题标签 #PassTheBaton 和 #传递接力棒。
