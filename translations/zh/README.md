# Pass the Baton

**适用于人民的规则，也应适用于领导他们的人。**

在世界各地，人们到了一定年龄就会把工作交给下一代。这个运动请求领导人也这样做。这不是出于对老年人的不信任，而是出于对更新的尊重。

## 我们的诉求

**凡已达到本国法定退休年龄的人，最迟到67岁，不再开始最高职位上的新任期。**

这是一个全球性、非暴力、无党派的运动。话题标签：#PassTheBaton 和 #传递接力棒
