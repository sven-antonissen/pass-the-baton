# Pass the Baton («Передай эстафету»)

**То, что действует для людей, должно действовать и для тех, кто ими руководит.**

Во всём мире люди в определённом возрасте передают свою работу следующему поколению. Это движение просит лидеров поступать так же.

## Наше требование

**Тот, кто достиг установленного законом пенсионного возраста своей страны, но не позднее 67 лет, не начинает новый срок на одной из высших должностей.**

Не из недоверия к пожилым людям, а из уважения к обновлению.

Мы за ненасилие и вне партий. Присоединяйтесь к нам с хештегами #PassTheBaton и #ПередайЭстафету.
