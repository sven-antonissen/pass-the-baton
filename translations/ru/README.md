# Pass the Baton

**То, что действует для людей, должно действовать и для тех, кто ими руководит.**

Во всём мире люди в определённом возрасте передают свою работу следующему поколению. Это движение просит руководителей сделать то же самое. Не из недоверия к пожилым людям, а из уважения к обновлению.

## Наше требование

**Тот, кто достиг установленного законом пенсионного возраста своей страны, но не позже 67 лет, не начинает новый срок на одной из высших должностей.**

Глобальное, ненасильственное и беспартийное движение. Хештеги: #PassTheBaton и #ПередайЭстафету
