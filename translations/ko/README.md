# Pass the Baton

**국민에게 적용되는 원칙은 국민을 이끄는 사람들에게도 적용되어야 합니다.**

세계 어디서나 사람들은 일정한 나이가 되면 자신의 일을 다음 세대에 넘겨줍니다. 이 운동은 지도자들에게도 똑같이 해 달라고 요청합니다.

## 우리의 요구

**자국의 법정 정년에 이른 사람, 그리고 늦어도 67세가 된 사람은 최고위 공직에서 새 임기를 시작하지 않습니다.**

어르신을 믿지 못해서가 아닙니다. 새로운 시작을 존중하기 때문입니다.

Pass the Baton은 비폭력, 초당파의 세계적 운동입니다. 해시태그: #PassTheBaton · #바통넘기기
