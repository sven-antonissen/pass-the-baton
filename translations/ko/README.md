# Pass the Baton

**국민에게 적용되는 것은 국민을 이끄는 사람에게도 적용되어야 합니다.**

전 세계 사람들은 일정한 나이가 되면 자신의 일을 다음 세대에게 넘깁니다. 이 운동은 지도자들에게도 같은 일을 요청합니다. 나이 든 분들을 불신해서가 아니라, 새로운 시작을 존중하기 때문입니다.

## 우리의 요구

**자국의 법정 은퇴 연령에 도달한 사람, 그리고 늦어도 67세가 된 사람은 최고위직에서 새 임기를 시작하지 않습니다.**

Pass the Baton은 비폭력, 초당파의 세계적 운동입니다. 해시태그: #PassTheBaton, #바통을넘겨요
