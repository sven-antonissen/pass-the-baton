# Pass the Baton

**Ce qui vaut pour le peuple doit valoir pour ceux qui le dirigent.**

Partout dans le monde, les gens passent le relais à la génération suivante à un certain âge. Ce mouvement demande à ceux qui dirigent d’en faire autant. Non par défiance envers les personnes âgées, mais par respect pour le renouvellement.

## La demande

Toute personne qui a atteint l’âge légal de la retraite de son propre pays, et au plus tard 67 ans, ne commence pas de nouveau mandat dans l’une des plus hautes fonctions.
