# Het Stokje Doorgeven

**Wat voor het volk geldt, geldt ook voor wie het volk leidt.**

*English: [Pass the Baton](../../README.md)*

Overal ter wereld geven mensen op een bepaalde leeftijd hun werk door aan een volgende generatie. Deze beweging vraagt dat leiders hetzelfde doen: wie de wettelijke pensioenleeftijd van zijn eigen land bereikt, en uiterlijk op 67 jaar, begint geen nieuw mandaat in een van de hoogste ambten.

Niet uit wantrouwen tegenover ouderen, maar uit respect voor vernieuwing.
