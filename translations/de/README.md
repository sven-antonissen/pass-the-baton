# Pass the Baton

**Was für die Menschen gilt, soll auch für die gelten, die sie führen.**

Überall auf der Welt geben Menschen in einem bestimmten Alter ihre Arbeit an die nächste Generation weiter. Diese Bewegung bittet die Führenden, dasselbe zu tun. Nicht aus Misstrauen gegenüber älteren Menschen, sondern aus Respekt vor Erneuerung.

## Die Forderung

**Wer das gesetzliche Rentenalter des eigenen Landes erreicht hat, spätestens aber mit 67, beginnt keine neue Amtszeit in einem der höchsten Ämter.**

Pass the Baton ist eine weltweite, gewaltfreie und überparteiliche Bewegung. Hashtag: #PassTheBaton oder #StaffelstabWeitergeben.
