# Pass the Baton

**Was für die Menschen gilt, soll auch für diejenigen gelten, die sie führen.**

Auf der ganzen Welt geben Menschen ab einem bestimmten Alter ihre Arbeit an die nächste Generation weiter. Diese Bewegung bittet die Führenden, dasselbe zu tun. Nicht aus Misstrauen gegenüber älteren Menschen, sondern aus Respekt vor Erneuerung.

## Unsere Forderung

**Wer das gesetzliche Rentenalter seines Landes erreicht hat, spätestens aber mit 67, tritt keine neue Amtszeit in einem der höchsten Ämter an.**

Wir sind eine weltweite, gewaltfreie und überparteiliche Bewegung. #PassTheBaton #StaffelstabWeitergeben
