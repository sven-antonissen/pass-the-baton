# Pass the Baton(バトンを渡そう)

**国民に当てはまるルールは、国民を導く人にも当てはまるべきです。**

世界のどこでも、人はある年齢で仕事を次の世代に引き継ぎます。この運動は、リーダーにも同じことを求めます。年長者を信頼していないからではありません。世代交代を大切に思うからです。

## 私たちの要求

**自国の法定退職年齢に達した人、遅くとも67歳に達した人は、最高位の公職で新しい任期を始めない。**
