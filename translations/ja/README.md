# Pass the Baton

**国民に当てはまることは、国民を導く人にも当てはまるべきです。**

世界中どこでも、人は一定の年齢になると仕事を次の世代に引き継ぎます。この運動は、リーダーにも同じことをお願いします。

**私たちの要求：** 自国の法定退職年齢に達した人、遅くとも67歳に達した人は、最高位の公職で新たな任期を始めません。

年長者を信頼していないからではなく、世代交代を大切に思うからです。この運動は非暴力で、どの政党にも属さず、誰にでも開かれています。#PassTheBaton #バトンをつなごう
