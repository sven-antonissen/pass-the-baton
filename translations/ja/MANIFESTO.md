# マニフェスト:Pass the Baton

## 中心となるメッセージ

**国民に当てはまるルールは、国民を導く人にも当てはまるべきです。**

世界のどこでも、人はある年齢で仕事を次の世代に引き継ぎます。私たちは、リーダーにも同じことを求めます。年長者を信頼していないからではありません。世代交代を大切に思うからです。

## なぜか:問題点

世界中で、多くのリーダーが国民の退職年齢をはるかに超えています。これは民主主義の国でも、権威主義の体制でも同じです。

- **二重基準。** 看護師も、大工も、教師も、仕事を後進に譲ります。何百万人もの暮らしを左右する人は、最後まで居座ることが少なくありません。
- **短い時間軸。** 気候、債務、年金に関する決定は、その結果を自分たちで負うことになる世代に、最も大きく影響します。
- **刷新が妨げられる。** 去らない人がいると、新しい考え、新しい人、新しい力の居場所がなくなります。
- **役割への注意が足りない。** 世界の指導者には、毎日、全力で取り組むことが求められます。どの年齢でも重い仕事ですが、高齢ならなおさらです。

## 私たちの要求

**自国の法定退職年齢に達した人、遅くとも67歳に達した人は、最高位の公職で新しい任期を始めない。**

- 世界中のすべての国、すべての体制に適用します。まず最高位の職、つまり国家元首、政府の長、大臣から始めます。第2段階で、他の政治的な職にも広げます。
- 上限を、人々がすでに受け入れているものに結びつけます。それは退職年齢であり、世界共通の上限は67歳です。
- すでに始まっている任期は、全うしてかまいません。新しい任期は始めません。
- 一般の市民は、これまでどおり自由に働き続けられます。国を率いる人はより重い責任を負い、パイロットや裁判官と同じように、より厳しい基準に従います。

## 私たちの原則

1. **平等。** 国民に求められる年齢の基準を、国民に仕えるリーダーにも同じように当てはめます。
2. **敬意。** 私たちは高齢者に反対しているのではありません。経験は、助言者、指導者、大使として、これからも貴重です。
3. **刷新。** バトンを渡すことは、リーダーとしての行動であり、敗北ではありません。
4. **非暴力。** 私たちは説得します。力は決して使いません。
5. **独立。** 左にも右にも味方しません。この基準はすべての人に当てはまります。

## 反対意見への答え

| 反対意見 | 私たちの答え |
| --- | --- |
| 年齢は、その人個人について何も語らない。 | そのとおりです。しかし、裁判官やパイロットには、すでに一律の年齢制限を受け入れています。誰がまだ「十分に元気」かを毎回議論するより、明確なルールのほうが公平です。 |
| これは年齢差別だ。 | 誰もが働き続ける権利を持ち続けます。最高位の職だけが、より厳しい基準に従います。何百万人もの暮らしに関わるからです。 |
| 有権者は自由に選べるべきだ。 | 有権者は、任期制限や最低年齢などの制限をすでに受け入れています。年齢の上限は、その論理的な裏返しです。 |
| 危機のときは経験が最も大切だ。 | その経験はなくなりません。元リーダーは、権力を持たなくても、助言し、仲介し、人々を鼓舞できます。 |
| 独裁国家では国民に発言権がない。 | だからこそ、これを世界共通の規範にする必要があります。他の国で当たり前になるほど、それを避ける人への圧力は強まります。 |

## 進め方:シンボル、瞬間、行動

- **シンボル:バトン。** リレーのバトンを、画像、しぐさ、モノとして使います。人々はオンラインでも街頭でも、互いにバトンを渡します。どの言語、どの文化でも分かります。
- **ハッシュタグ:** #PassTheBaton。#バトンを渡そう のような地域版も使います。
- **瞬間:年に一度の世界行動デー。** 同じ日に、世界中の人が広場で、職場で、オンラインで、象徴的にバトンを渡します。
- **顔ぶれ。** 若者と、すでにバトンを渡した退職者の両方です。これは若者対高齢者の対立ではないことを示します。
- **地域ごとの翻訳。** 各国が、この要求を自国の退職年齢と自国のリーダーに結びつけます。
- **最初の一歩。** できるだけ早く、2段階で始めます。まずオンライン(マニフェスト、登録できるウェブサイト、ハッシュタグ)。次に、複数の国に支持者が集まったら、最初の現地行動デーを開きます。
