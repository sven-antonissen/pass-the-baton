# マニフェスト：Pass the Baton

## 中心となるメッセージ

**国民に当てはまることは、国民を導く人にも当てはまるべきです。**

世界中どこでも、人は一定の年齢になると仕事を次の世代に引き継ぎます。私たちは、リーダーにも同じことをお願いします。年長者を信頼していないからではありません。世代交代を大切に思うからです。

## なぜ：問題点

世界各地で、多くのリーダーが国民の退職年齢をはるかに超えています。これは民主主義の国にも、権威主義の体制にも当てはまります。

- **二重基準。** 看護師も、大工も、教師も、仕事を後進に引き継ぎます。何百万人もの暮らしを左右する人は、職業人生の最後まで居続けることがよくあります。
- **短い時間軸。** 気候、債務、年金に関する決定は、その結果を自ら背負うことになる世代に、最も大きく影響します。
- **刷新が妨げられる。** 去らない人がいると、新しい考え、新しい人材、新しい活力の居場所がなくなります。
- **役割への注意が足りない。** 世界の指導者の務めは、毎日、全力を注ぐことを求めます。どの年齢でも重い仕事ですが、高齢になるほどなおさらです。

## 私たちの要求

**自国の法定退職年齢に達した人、遅くとも67歳に達した人は、最高位の公職で新たな任期を始めません。**

- 世界中のすべての国、すべての体制に適用します。まず最高位の職、つまり国家元首、政府の長、大臣から始めます。第二段階で、他の政治的な職にも広げます。
- 上限は、人々がすでに受け入れているものに結びつけます。つまり退職年齢で、世界共通の上限は67歳です。
- すでに始まっている任期は全うできます。新しい任期は始めません。
- 一般の市民は、これまでどおり自由に働き続けられます。国を率いる人はより重い責任を負い、パイロットや裁判官のように、より厳しい基準の対象となります。

## 私たちの原則

1. **平等。** リーダーにも、彼らが仕える市民と同じ年齢の基準を。
2. **敬意。** 私たちは年長者に反対しているのではありません。経験は、助言者、指導者、大使として、これからも価値があります。
3. **刷新。** バトンを渡すことは、リーダーシップの行為であり、敗北ではありません。
4. **非暴力。** 私たちは説得します。力は決して使いません。
5. **独立性。** 左でも右でも、どちらの側にも立ちません。この基準はすべての人に当てはまります。

## 反論への答え

| 反論 | 私たちの答え |
| --- | --- |
| 年齢は、その人個人について何も語らない。 | そのとおりです。しかし、裁判官やパイロットには、すでに定められた年齢の限度を受け入れています。明確なルールは、誰がまだ「十分に健康」かを毎回議論するよりも公平です。 |
| これは年齢差別だ。 | 誰もが働き続ける権利を持ち続けます。厳しい基準を負うのは最高位の職だけです。何百万人もの暮らしに関わるからです。 |
| 有権者は自由に選べるべきだ。 | 有権者はすでに、任期の制限や最低年齢などの制約を受け入れています。年齢の上限は、その論理的な対になるものです。 |
| 危機のときこそ経験が重要だ。 | その経験はなくなりません。元リーダーは、権力を持たなくても、助言し、仲介し、人々を励ますことができます。 |
| 独裁国家では国民に発言権がない。 | だからこそ、これは世界共通の規範にする必要があります。他の国で当たり前になるほど、それを避ける人への圧力は高まります。 |

## 進め方：シンボル、時、行動

- **シンボル：バトン。** リレーのバトンを、画像、しぐさ、あるいは物として使います。人々はオンラインでも街なかでも、互いにバトンを渡します。どの言語、どの文化でも伝わります。
- **ハッシュタグ：** #PassTheBaton。地域版として #バトンをつなごう のようなものも使えます。
- **時：年に一度の世界同時アクションデー。** 同じ日に、世界中の人が、広場で、職場で、オンラインで、象徴としてバトンを渡します。
- **顔ぶれ。** 若者と、すでにバトンを渡した退職者の両方です。これは、若者対高齢者の構図ではないことを示します。
- **各地の言葉に。** 各国が、この要求を自国の退職年齢と自国のリーダーに結びつけます。
- **最初の一歩。** できるだけ早く、二段階で始めます。まずオンライン（マニフェスト、登録のあるウェブサイト、ハッシュタグ）。次に、複数の国に賛同者がそろったら、最初の実際のアクションデーを行います。

## 顔となる人の候補

力のある顔は、メッセージそのものを体現します。声をかけたいのは次のような人たちです。

| 人物像 | 効果的な理由 |
| --- | --- |
| 自ら早めに退いた元リーダー | 退くことがリーダーシップの行為だという生きた証。最も強い信頼性。 |
| 自分でバトンを渡した退職者 | 「若者対高齢者」ではないことの証明。年長の有権者に語りかけられる。 |
| リレー選手 | バトンはまさに本業。よく知られ、好感を持たれ、政治的に中立。 |
| 若い活動家または学生 | 若者とソーシャルメディアに、活力と広がりをもたらす。 |
| 二人組：年長者と若者 | 「渡す」場面そのもの。おそらく最も強い選択肢。 |
