# Pass the Baton

**Kinachowahusu wananchi kiwahusu pia wale wanaowaongoza.**

Kote duniani, watu hukabidhi kazi zao kwa kizazi kijacho wanapofikia umri fulani. Harakati hii inawaomba viongozi wafanye vivyo hivyo.

**Madai yetu:** mtu yeyote aliyefikia umri wa kustaafu kisheria wa nchi yake, na kwa kiwango cha juu miaka 67, haanzi muhula mpya katika mojawapo ya nafasi za juu kabisa za uongozi.

Si kwa kutowaamini wazee, bali kwa kuheshimu upya na mabadiliko. Harakati hii haitumii vurugu, haifungamani na chama chochote, na iko wazi kwa kila mtu. #PassTheBaton #PeanaKijiti
