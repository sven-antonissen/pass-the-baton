# Pass the Baton (Kabidhi Kijiti)

**Kinachowahusu wananchi kiwahusu pia wanaowaongoza.**

Kote duniani, watu hukabidhi kazi yao kwa kizazi kijacho wanapofikia umri fulani. Harakati hii inawaomba viongozi wafanye vivyo hivyo.

## Madai yetu

**Mtu yeyote aliyefikia umri wa kustaafu wa kisheria wa nchi yake, na kwa kuchelewa zaidi miaka 67, haanzi muhula mpya katika mojawapo ya nyadhifa za juu kabisa.**

Si kwa kutowaamini wazee, bali kwa kuheshimu upya na mabadiliko.

Sisi ni wa amani na hatufungamani na chama chochote. Jiunge nasi kwa hashtag #PassTheBaton na #KabidhiKijiti.
