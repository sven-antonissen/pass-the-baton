# Pass the Baton

**O que vale para o povo deve valer para quem o governa.**

Em todo o mundo, as pessoas passam o seu trabalho para a geração seguinte a partir de certa idade. Este movimento pede aos líderes que façam o mesmo.

## A reivindicação

**Quem atingiu a idade legal de aposentadoria do seu próprio país, e no máximo aos 67 anos, não inicia um novo mandato em um dos mais altos cargos.**

Não por desconfiança dos mais velhos, mas por respeito à renovação.

Somos um movimento global, não violento e apartidário. Use a hashtag **#PassTheBaton** (em português: **#PasseOBastão**).
