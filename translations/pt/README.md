# Pass the Baton

**O que vale para o povo deve valer para quem o dirige.**

Em todo o mundo, as pessoas passam o seu trabalho à geração seguinte a partir de certa idade. Este movimento pede aos líderes que façam o mesmo. Não por desconfiança em relação às pessoas mais velhas, mas por respeito pela renovação.

## A exigência

**Quem tiver atingido a idade legal de reforma do seu próprio país, e no máximo aos 67 anos, não inicia um novo mandato num dos mais altos cargos.**

Pass the Baton é um movimento mundial, não violento e apartidário. Hashtag: #PassTheBaton, ou #PassaOBastão.
